#+title: SSTable

aka Sorted String Table

Immutable segment files of key-value pairs sorted by key stored on disk indexed
using a sparse in-memory hash map.

* Advantages

- Sorted segment files can be merged quickly (using Mergesort) and deleted
  after.
  
- In-memory hash index does not need to be fully populated, since offsets can be
  inferred from other key offsets
  
- Sequential ranges of key-value between keys in the hashmap may be compressed
  to save disk space and I/O bandwidth (number of bytes transferred from storage
  to memory).
