#+title: Delta Lake

Optimized storage layer that are simply [[id:9b1e5e2a-22f2-4288-9d64-ad6f3c152c7f][Parquet]] files in cloud object storage,
alongside a transaction log (~delta_log/~) that provides the foundation for
tables in a [[id:799590f5-0593-475e-8e6c-f208c369dec7][Lakehouse]] on [[id:bd57f66a-6bdf-47d7-a37a-ff265b2e6b69][Databricks]].

* ~delta_log/~

The transaction log is an ordered, append-only record of every change made to
the Delta table that acts as the single source of truth of the table's current
state.
