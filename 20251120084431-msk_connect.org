#+title: MSK Connect (AWS)

Amazon's fully managed service built on open-source Kafka Connect, simplifying
the streaming of data to and from MSK clusters.

Source connectors pull data from a data source and push this data into a
cluster, whereas a sink connector pulls data from a cluster and pushes said data
into a data sink.
