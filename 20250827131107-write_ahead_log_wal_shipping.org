#+title: Write-Ahead Log (WAL) Shipping

Implementation of leader-based replication logging where the storage engine log
(append-only sequence of bytes containing all database writes), can be used to
build a replica on another node.

* Issues

The implementation is tightly coupled to the storage engine. Both the leader and
followers need to have the same versions of the database software.
