#+title: Git

Distributed version control system.

* Commands

~git fetch~ Downloads remote repository changes to the local repository

~git merge~ Integrates source branch changes into a target branch

~git pull~ Combination of ~git fetch~ and ~git merge~

~git cherry-pick~ Apply specific commits in a branch to another
