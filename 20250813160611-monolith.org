#+title: Monolithic Architecture

Architecture where the entire application code and its dependencies are packaged
into a single deployable artifact.

Usually all instances share a single database.

* Why don't monolithic applications scale well?

- Singular changes require rebuilding and redeploying the entire application
- Single crash brings down the entire system
- Can only scale the entire application, not singular components
