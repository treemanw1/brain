#+title: Software Versioning

Standard is semantic versioning (SemVer), e.g. =major.minor.patch=

- Major: Breaking changes
- Minor: Non-breaking features
- Patch: Lowest risk changes

* What constitutes a breaking change?

Change to a public API that is not backward-compatible.
