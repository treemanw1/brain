#+title: Apache Kafka

Distributed event streaming platform for very high-throughput, fault tolerant
ordered data streams.

Append-only log where events are written to the end of each strictly-ordered
[[id:0d38bfd6-b2c4-4e4d-a6c1-7a2cb9909f01][partition log]]. Events are written to disk sequentially using the OS page cache.
