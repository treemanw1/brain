#+title: Four-Step Dimensional Design Process

[[id:ea2d27bc-22bd-48db-a05c-d8a10f1b621b][Dimensional model]] design process outlined my Kimball.

1. Select the business process

   - Operational activities, e.g. taking order, processing claim
   - Corresponds to a single fact table

2. Define the grain

   - Grain: What a single fact table row represents

3. Identify the dimensions

   - 5Ws 1H context surrounding the business process event

4. Identify the facts

   - Measurements from the business process events
   - Almost always numeric
   - Should be consistent with the defined grain
