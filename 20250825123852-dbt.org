#+title: dbt

Data build tool (dbt) is an open-source command line tool that enables data
transformation (in the [[id:5b2e79f5-bb7b-4319-9246-106f4b053cf1][ETL]] process) of data in [[id:b61158a5-87d6-4895-891f-c4ced0f52b9b][data warehouses]] using SQL
statements.
