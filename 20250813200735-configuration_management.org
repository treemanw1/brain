#+title: Configuration Management

Management process that tracks and monitors changes to a software systems
configuration metadata.

* Why configuration management?

For example in a microservice architecture, each service has configuration
metadata, e.g. CPU/RAM resource allocations, secrets like passwords and
encryption keys.

Configuration management centralizes source of truth.
