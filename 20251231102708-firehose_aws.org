#+title: Firehose (AWS)

Amazon Data Firehose is a managed service for delivering real-time streaming
data to destinations e.g. S3, Redshift, HTTP endpoints.

* Firehose vs MSK Sink Connect

Firehose can ingest from different sources whereas MSK Sink Connect connects
purely to a MSK cluster.
