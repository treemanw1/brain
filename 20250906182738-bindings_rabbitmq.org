#+title: Bindings (RabbitMQ)

Routing configuration on an exchange. Bindings have the following properties:

1. Source Name (Exchange)

2. Destination Name (Queue, Stream or Exchange)

3. Destination Type

4. Optional map of arguments

Bindings inherit durability from their source and destination.
