#+title: Lazy Evaulation

Spark feature that holds off on executing transformations until an action is
executed for optimization purposes, e.g. keeping entire dataframe in memory for
a shorter duration.

For example, ~df.filter()~ will not filter the dataframe until an action, e.g.
~df.show()~ is ran.
