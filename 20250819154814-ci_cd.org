#+title: CI/CD

Continuous Integration & Continuous Delivery/Deployment

Software Development practice that automates process of integrating code
changes, testing, and deploying applications.

* Continuous Delivery vs Continuous Deployment

Continuous Delivery: Ensures code changes are always in a deployable state
before a manual production release.

Continuous Deployment: Automation of the deployment process to production
